# Magic Survival — Кооператив

Мод для [MS_KIT](https://github.com/Kysnez4/MS_KIT): Magic Survival на 2–4 игроков через интернет, в том числе из
разных городов и стран. Свой сервер (VPS) не нужен — он встроен в мод и запускается у одного из игроков (хоста) по
кнопке. Телефоны соединяются через бесплатную виртуальную сеть: Anywherelan, Tailscale или ZeroTier.

> **Игрокам нужен только файл [`coop.zip`](https://github.com/OneCOlyl/msm/releases/latest/download/coop.zip)** из
> [последнего релиза](https://github.com/OneCOlyl/msm/releases/latest) и компоненты MS_KIT (см. [установку](docs/INSTALL.md)).
> Остальное в репозитории — исходный код для тех, кто хочет изменить или пересобрать мод.

## Для игроков

### Что даёт мод

- Друзья **появляются в вашем бою союзниками** — цветными копиями героя. Союзник двигается так же, как друг у себя, и
  **повторяет его магию**: снаряды, Щит, Спутники, Духи, Электрозону и Армагеддон.
- **Общая пауза:** пока кто-то выбирает умение, игра на паузе у всех, и бой у всех начинается вместе.
- Под союзником — **полоска здоровья**, а если он ушёл за край экрана — **стрелка в его сторону**.
- Кнопка **«Лечить»**, когда другу плохо, и сигнал **«нужна помощь!»**, когда плохо вам.
- **Общие враги** (экспериментально, по умолчанию выключено): у всех игроков враги хоста.

Подробно — в [описании возможностей](docs/FEATURES.md).

### Что понадобится

- Android-телефон с процессором **arm64** у каждого игрока.
- Игра **Zombix на MelonLoader** с ядром и библиотеками ModKit из [MS_KIT](https://github.com/Kysnez4/MS_KIT/releases).
  Это клон Magic Survival с поддержкой модов; оригинальная игра остаётся на месте, сохранения у клона свои.
- Мод [`coop.zip`](https://github.com/OneCOlyl/msm/releases/latest/download/coop.zip) — **одной версии у всех игроков**.
- Одно и то же приложение виртуальной сети у всех:
  [Anywherelan](https://f-droid.org/packages/com.anywherelan.awl/),
  [Tailscale](https://tailscale.com/download/android) или
  [ZeroTier](https://www.zerotier.com/download/).

### Быстрый старт

1. **Установите** Zombix, ModKit и мод на каждый телефон — [пошаговая инструкция](docs/INSTALL.md).
2. **Объединитесь в виртуальную сеть** — [Anywherelan, Tailscale или ZeroTier](docs/CONNECT.md#виртуальная-сеть).
3. **Хост создаёт игру:** главное меню → кнопка «Кооп» вверху по центру → «Создать игру (я хост)». Адрес, который
   нужно сообщить друзьям, отмечен «← VPN».
4. **Остальные подключаются:** «Кооп» → четыре числа IP хоста, порт `8766` → «Подключиться». В статусе появится
   «на связи, пинг … мс».
5. **Начните бой** — каждый у себя. Друзья появятся у вас союзниками.

Не подключается — смотрите [проверку соединения](docs/CONNECT.md#проверка-соединения) и
[таблицу сообщений](docs/CONNECT.md#если-не-подключается).

### Важно знать

- **У каждого свой мир.** Свои враги, уровень, заклинания и артефакты; друг приходит к вам союзником и помогает
  сражаться. Полностью общий бой игра не позволяет — кроме экспериментального режима «Общие враги».
- **Хост держит игру открытой.** Сервер работает в его игре; свёрнутую игру Android приостанавливает.
- **Соединение не шифруется и без пароля.** Играйте только внутри виртуальной сети и не открывайте порт 8766 в интернет.
- Все ограничения и что проверено — в разделе [«Известные ограничения»](docs/FEATURES.md#известные-ограничения).

## Для разработчиков

Сборка, упаковка в `dist/coop.zip` и все тесты (нужны .NET SDK 8 и Python 3):

```bash
bash build.sh
```

Основное:

| Путь | Что там |
|---|---|
| `mod/coop/` | Исходники мода; `Net/` — сетевой код без зависимостей от Unity. |
| `server/` | Отдельный сервер комнат `coop_server.py` и проверка связи без игры `coop_client.py`. |
| `tests/` | Тесты сети (против обоих серверов), имитация игры с двумя модами, проверки отладочных модов. |
| `libs/`, `stubs/` | Библиотеки MS_KIT и заглушки Unity для сборки без телефона. |

Структура репозитория, протокол v2, проверка на телефоне и выпуск релиза — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Состояние проекта

Версия в репозитории — **1.6.58**. Если на [странице релизов](https://github.com/OneCOlyl/msm/releases) её ещё нет,
последний опубликованный релиз старше; установите его у всех игроков. Мод собран против `ModKit.dll` и библиотек
из MS_KIT 2.0.

Проверено на двух телефонах (хост и гость) через Anywherelan. Пока не проверено на телефонах: Tailscale и ZeroTier,
3–4 игрока (только автотесты на ПК), разные разрешения экрана. Каждый релиз проходит проверку по
[чек-листу](docs/RELEASE_CHECKLIST.md); результаты — в [docs/device-tests/](docs/device-tests/).
