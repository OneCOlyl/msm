# Инструменты разработчика

Три мода ModKit для проверки «Кооператива» на телефонах. Игрокам они не нужны: чит и полигон меняют ход боя.
Выходят одним релизом с меткой `tools-<версия>` (workflow `tools-release`), отдельно от релизов «Кооператива».

| Мод | Что делает | Нужны библиотеки MS_KIT |
|---|---|---|
| `coop_debug` — «Кооператив: отладка» | Консоль на порту 8770: читать и менять поля игры во время боя, вызывать методы, ставить хуки. | — |
| `coop_cheat` — «Чит: заклинания» | Кнопка «ЧИТ» в бою: уровни заклинаний, особенностей, пассивов, артефактов, комбинаций и синергий, уровень героя. | `modkit_spells`, `modkit_spells_data`, `modkit_effects`, `modkit_data` |
| `coop_lab` — «Кооператив: полигон» | Кнопка «ПОЛИГОН» в бою: спокойная арена, любые мобы, механики боя, проверки кооператива с ПК. | `modkit_combat`, `modkit_hero` |

## Установка

1. Скачайте из релиза `tools-<версия>` нужные архивы: `coop_debug.zip`, `coop_cheat.zip`, `coop_lab.zip`.
2. Положите их на телефон в `/sdcard/Download/` и поставьте в Zombix: «Моды» → «+».
3. Новый мод ModKit выключен: включите его в окне «Моды» и перезапустите игру.

По USB то же самое: `adb push coop_lab.zip /sdcard/Download/`.

## coop_debug — отладочная консоль

Консоль слушает порт 8770 только на самом телефоне, с ПК к ней ходят через USB:

```bash
adb forward tcp:8771 tcp:8770
python tools/coop_dbg.py 8771 "get mgr.Time_Sec" "ls hero Circle"
```

Команды: `get`, `ls`, `lsall`, `methods`, `nested`, `set`, `call`, `hook`, `skip`, `iters`, `find`. Корни путей:
`hero` (герой), `mgr` (менеджер боя), `abil` (менеджер способностей), `db` (`Z_Database`), `T:<сборка>:<тип>` и
`U:<тип Unity>` (статические члены), `found` (результат `find`). Полный список — команда `help`.

## coop_cheat — чит

В бою кнопка «ЧИТ» справа открывает панель:

- вкладки: магии, особенности, спецпассивы, пассивы, артефакты, прочее, исследования, зачарования, комбинации,
  синергии;
- нажатие на запись даёт +1 уровень, в режиме «−1 уровень» снимает уровень;
- «Уровень героя +1» сразу открывает окно выбора магии: чит выдаёт ровно ту ману, которой не хватает до уровня;
- «Все магии — максимум» поднимает все 21 заклинание до предела одним нажатием.

Уровень выдаётся тем же путём, что и выбор в игре: запись в список выученного и пересчёт героя. Если уровень не
вырос, чит пишет его напрямую. Какой путь сработал, видно в журнале (`[coop_cheat]`).

## coop_lab — полигон

В бою кнопка «ПОЛИГОН» открывает три вкладки:

- «Арена»: спавн игры, бессмертие, опыт, стоп и перемотка часов, убрать или убить врагов;
- «Мобы»: любой тип врага (0–50), эпические, особые, переход;
- «Механики»: часы к боссу, босс-волна, обелиск, смена области, притягивание маны, предмет по номеру.

Особенности:

- без опыта не открываются окна выбора магии, но кнопка уровня героя в чите работает;
- «Сдаться» и «Выход» сами выключают бессмертие, иначе бой не закончится;
- магии полигон выдаёт через `coop_cheat` (`Spell <id> <уровень>`), без чита эта команда не работает.

Те же действия с ПК через консоль `coop_debug`: `call T:coop_lab:MagicSurvivalLab.Lab/Current.Spawn 6 10`, `.Status`,
`.CoopStatus`. Для автоматики: `Buttons` (активные кнопки интерфейса: путь, место, доступность, текст), `Click <номер> <путь>`
(нажатие, как касанием), `Pickups` (лежащие сундуки, торговец, обелиски), `GoTo <x> <y>` (герой в точку). Сценарии проверок на двух телефонах — `tools/lab.py` (см. [DEVELOPMENT.ru.md](DEVELOPMENT.ru.md#полигон)).

## Выпуск

У трёх модов одна версия, она берётся из метки `tools-X.Y.Z`. Поставьте метку на коммит и отправьте её:

```bash
git tag tools-0.2.0 && git push origin tools-0.2.0
```

GitHub соберёт моды с этой версией, прогонит тесты и опубликует релиз с тремя архивами. Версия попадёт в описание
релиза.
