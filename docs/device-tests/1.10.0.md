# Checking 1.10.0 on phones

Date: 2026-11-11. Claude Code installed the builds, ran the `tools/lab.py` and `tools/phones.py` scenarios, called
methods through the `coop_debug` console, looked at screenshots and read both phones' `modkit.log`. After that the user
checked the new settings on the phones and confirmed that everything works.

| Phone | Android | Resolution | Role |
|---|---|---|---|
| Xiaomi 25042PN24C | 16 | 1440×3200 | host |
| Google Pixel 3a | 12 | 1080×2220 | guest |

The builds are the working copy on top of `8c3edf9` (the logs say `кооператив 1.9.1-1-g8c3edf9-dirty.<time> включён`);
the mod code in the last build is the same as in the release commit. A `VERSION=1.10.0` candidate wasn't installed on
the phones before the release. The room went through the Anywherelan tunnel; shared enemies, shared pause and shared
chests on, area 1.

What's new: the «ХП врагов, ×» (enemy health) and «Урон врагов, ×» (enemy damage) settings; the host sets the battle
rules.

## Known limits

- `lab.py mobs` sometimes has one failure «гость ранил: у хоста —» (the host's enemy didn't die from the guest's
  damage), each time for a different mob kind. On the build without the changes: 44 PASS / 0 FAIL and 42 PASS / 1 FAIL
  with the same failure, so this flakiness was there before.
- «НЕТ» for types 25 and 50 in `lab.py mobs`, as in 1.9.0 and 1.9.1.
- A freshly spawned enemy lives with normal health for up to 0.2 s until the mod scales it.
- `perf`, 3–4 players, a Wi-Fi drop, minimizing the game and turning the mod off weren't checked: those parts didn't
  change in 1.10.0.
