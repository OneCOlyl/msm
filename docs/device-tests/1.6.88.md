## Logs

- Load: no battle summary (`кадр за бой`), because the player's battle hadn't ended when the logs were collected.
- No `ОШИБКА [coop]`, `ошибки обработчиков за бой` or `отключён из-за ошибок` lines in the player's battle at either host or guest.
- Host crash at 16:44:26 (Claude Code's battle, 4:01, wave 3): `Assertion mono-threads-posix.c:175, condition 'info->suspend_source == MONO_THREAD_SUSPEND_SOURCE_RUNTIME' not met`, then SIGABRT. In this battle `C_Battle_AllyUnit.Unit_Damage` was replaced through `coop_debug` (the `skip` command, so heroes wouldn't die): every hit on a hero went through managed code. The same crash happened on 25.10 on 1.6.46 from hooks on mass game objects. The player's battle without this replacement had no crashes. The `lastrun.txt` marks (`coop · таймер Every`, `союзники`) show where the mod's thread was when it stopped.
- At 16:44:23 the game threw `IndexOutOfRangeException` three times in `X_Select_Ability.OnEnable` (from `V_Ability_Manager.ManaGain`); there is no mod code in the stack.

## Testing without a player: notes

- Fast-forwarding the clock (`set db.Game_SurvivalTime`) doesn't work for boss gathering: the game doesn't set `Battle_ClearWaveON`, which the mod uses to detect a boss wave. The battle has to be played to 3:00.
- A damage multiplier and hero health via the console don't help: the game recalculates health back to 200, and boss wave damage bypasses `UnitApply_HitDamageRatio`. `skip C_Battle_AllyUnit Unit_Damage 3` (coop_debug 0.1.6) keeps the hero alive, but on wave 3 and later the game crashed with it (see above).

## Known limitations

- A guest far from the host sometimes gets `общие враги: выключено (хост не присылает врагов)` 1–6 s after a shared pause ends (4 times in 11 minutes), and ~10 s later `отошёл … — свой спавн включён` again. The host's enemy copies are recreated in those seconds.
- If the boss wave at the guest started before the host's state arrived, at the moment of the move the arena is set around the guest and switches to the host's arena with the host's first state.
- Two phones and one VPN were tested; 3–4 players, connection loss and turning the mod off mid-battle weren't tested in this release.
