## Known limitations

- The Pixel 3a was warm during the run (Thermal Status 2, battery 37 °C), so the guest's FPS (20.9) is low: cool, on
  the task 9 branch, it was 48. Don't compare it with earlier runs.
- The host sent 27 KB/s in this run against 18.6 KB/s on the task 9 branch: this build includes smooth copies (task 7)
  with positions at 0.01 precision. This was not measured separately.
- 3–4 players, VPN, Wi-Fi drop, minimizing the game and turning the mod off were not tested: these parts did not change
  in 1.8.0.
