## Журналы

- Найдено и исправлено по ходу: на 1.6.117–1.6.118 экран локации, открытый у гостя после смены локации хостом, показывал прежнюю картинку; вызов `AreaLevelInf` с номером не той локации рисовал Terra (сложность есть только у локации 14).
- Строк `ОШИБКА [coop]` и `отключён из-за ошибок` нет. Строки «прошлый запуск игры завершился аварийно» — от перезапуска игры через `am force-stop` при установке сборок.

## Известные ограничения

- Не проверены: сложность на Terra, платный вход в локацию у гостя, гость с закрытой у себя локацией хоста, гость, пришедший на экран локации после старта хоста.
- Однократное включение общих врагов при обновлении с 1.6 проверено только в ModSim: на телефонах они уже были включены.
